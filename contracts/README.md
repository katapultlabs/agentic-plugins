# contracts

A pointer skill. Before any contract work (MSA, SOW, DPA, NDA, referral or recruiting agreements), it makes the agent read Katapult's shared process doc in Google Drive and follow it:
[How we draft, send and sign contracts](https://docs.google.com/document/d/1b2FMsqQjw6BhLnwLUzbwveNAKmECFpqum8AJgKSdojQ/edit).

The process itself lives only in that doc, owned by Sara Calle, so people and agents share one baseline and changes go through the doc's suggestions and decision log. This plugin holds no process content and shouldn't need updates when the process changes.

Requires the Google Drive connector.

## Install

```
/plugin install contracts --marketplace katapultlabs/agentic-plugins
```

## Example triggers

- "Review Sara's MSA draft against our template"
- "Prepare the SOW for Acme and send it for redlines"
- "Check this DPA before we sign"
